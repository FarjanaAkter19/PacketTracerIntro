# PacketTracerIntro
Beginner Cisco Packet Tracer practice project focused on network topology design, connecting routers and switches, and exploring basic network infrastructure. Configurations and connectivity testing will be added as I continue learning.

## About
This is one of my first Cisco Packet Tracer practice projects, created while learning the fundamentals of computer networking.

## What I Practiced
- Connecting routers and switches
- Designing a basic network topology
- Connecting PCs and a server
- Exploring network links and device layouts

## Current Status
Topology design completed. IP addressing, device configuration, and connectivity testing are planned as my next steps.

## Tools
- Cisco Packet Tracer 9.0.1

## Learning Progress
This project is part of my ongoing journey to learn computer networking through hands-on practice.
